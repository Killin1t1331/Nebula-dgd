# Y. Lift the Veil 👁️✨

An esoteric text-analysis tool inspired by ancient symbolism, cryptograms, and the uncovering of hidden truths (*apokalypsis*). This tool explores the intersection of sacred geometry, letter-for-letter anagrams, and historical mythos—stripping away theatrical masks to reveal raw, foundational data.

## 🌟 Philosophy

*   **The Y (Source / Trinity):** Representing the root origin from which dualities split or converge. This tool traces concepts back to their core algorithmic or linguistic source.
*   **Lifting the Veil:** A programmatic mechanism for removing filters, obfuscations, and personas to look directly at the underlying architecture.

## 🚀 Features

*   **Esoteric Anagram Engine:** Permutes text inputs to find profound linguistic links and hidden phrases.
*   **Symbolic Mapping:** Translates inputs into ancient archetypal representations (e.g., Classical, Gnostic, or Kabbalistic variations).
*   **Theatrical Unmasking Mode:** Compares historical personas or strings against their raw, verified legal data structures.

## 🛠️ Installation

```bash
git clone https://github.com/your-username/y-lift-the-veil.git
cd y-lift-the-veil
pip install -r requirements.txt
```

## ⚙️ Quick Start

```python
from lift_the_veil import Unmasker

# Initialize the source engine
engine = Unmasker(source="Trinity")

# Uncover an anagram or hidden meaning
result = engine.reveal("Anton Szandor LaVey")
print(result) # Output: "Filth, ye elevate Satan"
```
